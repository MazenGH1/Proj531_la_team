# Projet Quiz

Présentation

Ce projet consiste à créer une application web de quiz permettant aux utilisateurs de répondre à des questions, d'obtenir un score et de consulter leurs résultats.
L'objectif de ce projet était de développer une application complète avec une partie serveur, une gestion de base de données et une interface utilisateur simple.
L'application permet de créer plusieurs quiz avec différentes questions et réponses, puis de laisser l'utilisateur répondre avant d'afficher son résultat final.

Fonctionnalités

- Affichage de la liste des quiz disponibles
- Création et gestion de quiz
- Système de questions avec plusieurs réponses possibles
- Calcul automatique du score après avoir terminé un quiz
- Enregistrement des résultats des utilisateurs logged in
- Système de connexion avec gestion des mots de passe
- Interface web avec des pages dédiées aux quiz et aux résultats

Technologies/Languages utilisées

- Python : langage principal du projet
- Flask : framework utilisé pour créer l'application web
- SQLite : gestion de la base de données
- HTML / CSS / JavaScript : création de l'interface utilisateur
- Git / GitHub / Trello / discord : gestion du versionnage du projet
